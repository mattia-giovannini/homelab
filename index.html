# Infrastructure I actually run, at home.

A small self-hosted lab — containers, observability, edge security — that doubles as a testbed for a different question: what does it take to give an agentic AI safe, scoped access to infrastructure that actually matters?

$ cat stack.json

Docker

Day-to-day container runtime for internal services that don't need rootless isolation.

Podman

Rootless, daemonless containers for anything internet-facing — smaller attack surface by default.

Kubernetes

Orchestration layer for services that need scheduling and self-healing across nodes.

Prometheus

Scrapes metrics from every service in the lab — the source of truth when something looks off.

Grafana

Dashboards for what Prometheus collects. Usually the first tab I open when something feels slow.

CrowdSec

Collaborative IP reputation and local behaviour detection, enforced through a custom ARM bouncer I maintain for the Raspberry Pi nodes.

Nginx Proxy Manager

Reverse proxy and TLS termination in front of everything that's actually exposed.

Hermes Agent

Nous Research's open-source agent platform. Scoped, read-only access to service status and logs — not free rein.

Claude Code

What I actually use for the infra work — writing Podman Quadlet units, debugging the proxy, building this page.

$ cat agentic-ai.md

The lab exists to answer a practical question, not a hypothetical one: what does it take to give an AI agent safe, scoped access to infrastructure that actually matters? Read-only where it should be, sandboxed where it needs to act, and always something a human can audit afterwards.

Hermes Agent gets a narrow diagnostic view — it can ask how a service is doing, not restart it. Claude Code, by contrast, does real work here under my direct supervision: writing the Podman Quadlet units, debugging the reverse proxy, shipping this page. The line between the two is deliberate.

$ cat about.md

Everything here runs on Raspberry Pi nodes and a couple of always-on machines at home. It's small on purpose — big enough to be useful, small enough that I still understand every piece of it.
